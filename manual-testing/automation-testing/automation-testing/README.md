## 🤖 Automation Testing Documentation

Este directorio está reservado para tests automatizados usando Selenium, Cypress o similar.

├── README.md
├── tests/

### 🚀 Cómo Empezar

1. Instala herramientas:
```bash
   pip install selenium pytest
```

2. Descarga ChromeDriver

3. Crea primer test

4. Ejecuta tests:
```bash
   pytest tests/
```

### 🛠️ Tech Stack

- Language: Python
- Framework: Selenium/Cypress
- Test Runner: pytest
- Browser: Chrome
