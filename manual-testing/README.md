# Manual Testing

## 📋 Test Cases Documentation

Este directorio contiene la documentación completa de pruebas manuales para una aplicación de ecommerce.

### 📄 Archivos Incluidos

**Test_Cases.xlsx** - Suite completa de test cases documentados

#### Estructura del Excel:
- **Test ID**: Identificador único de cada test case (TC-001, TC-002, etc)
- **Feature**: Módulo o funcionalidad testeada
- **Test Description**: Descripción clara del objetivo del test
- **Test Steps**: Pasos numerados y detallados para ejecutar
- **Expected Result**: Resultado esperado si todo funciona correctamente
- **Actual Result**: Lo que realmente sucede (completado durante ejecución)
- **Status**: PASS, FAIL, BLOCKED, o PENDING
- **Date**: Fecha de ejecución del test
